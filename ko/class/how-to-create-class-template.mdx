---
title: "수업 템플릿 등록하기"
description: "로우그래피에서 수업 템플릿을 등록하는 방법을 알려드릴게요."
---

수업 템플릿은 자주 사용하는 수업 정보를 미리 저장해 두는 기능이에요. 템플릿을 만들어 두면 매번 같은 내용을 입력하지 않고도 수업을 빠르게 등록할 수 있어요.

## 수업 템플릿 등록하기

<Steps>
  <Step title="수업 템플릿 설정은 설정 > 수업 템플릿에서 할 수 있어요.">
    좌측 메뉴의 '설정'에서 '수업 템플릿' 항목을 선택해 주세요.
  </Step>
  <Step title="'추가하기'를 클릭하면 수업 템플릿을 새로 추가할 수 있어요.">
    화면 우측 상단의 '추가하기' 버튼을 클릭해 주세요.
  </Step>
  <Step title="수업 템플릿 이름을 입력해 주세요.">
    템플릿을 쉽게 구분할 수 있도록 이름을 입력해 주세요.
  </Step>
  <Step title="수업 정보를 입력해 주세요.">
    과목, 담당 강사, 강의실, 정원 등 수업에 필요한 기본 정보를 입력해 주세요.
  </Step>
  <Step title="수업 일정을 설정해 주세요.">
    반복되는 요일과 시간을 설정하면 수업을 등록할 때 자동으로 적용돼요.
  </Step>
  <Step title="'등록하기' 버튼을 클릭하여 수업 템플릿을 추가할 수 있어요.">
    입력한 내용을 확인한 뒤 '등록하기' 버튼을 클릭하면 템플릿이 저장돼요.
  </Step>
</Steps>
